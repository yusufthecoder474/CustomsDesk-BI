# Create these Power Query parameters

In Transform data → Manage Parameters, create text parameters:

| Name | Default | Meaning |
|---|---|---|
| SourceMode | CSV | CSV or PostgreSQL (case-sensitive) |
| Server | 127.0.0.1:5434 | PostgreSQL host and port |
| Database | customsdesk | Database name |
| ExportFolder | C:\CustomsDesk-BI\data\exports | Absolute local folder, no trailing slash |

Credentials belong in Power BI Data source settings. Do not embed passwords in M.
Create fxLoad as a blank query/function with fxLoad.m. Create every table query using the matching .m file.
Disable load for fxLoad and parameters. Set each table query name to the filename without .m.

For the actual selected port and timestamped CSV folder, use POWER_BI_CONNECTION.json generated by the Windows workflow. Create the connection-only scalar query LatestSuccessfulRun before data_quality_results. It filters DQ to the latest successful run automatically.
